# Class Activities

## Journal Review

I have checked the 6-10 week records against the Journal checklist. Each week's records were completed according to the checklist requirements, and included data exploration, visual research, technical development, peer feedback, and project reflections. Text, images, and various versions of the programs developed in p5.js were all recorded. During the check, I found some incorrect links to program versions, which have since been corrected.

Three key moments guided the direction of this project.

The first was converting the raw tourism dataset from Stats NZ into a CSV file that could be used by the program. This process taught me that not all data formats can be directly applied to development. CSV was not just a change in file storage format, but more importantly, a change in data table format. Only data tables with a database structure could be effectively used in p5.js.

The second was finding a suitable world map JSON. After downloading, the GeoJSON world map was successfully loaded. This transformed the graphical display from simple charts into spatial visualisations capable of conveying geographical relationships.

The third is feedback from peers in the past few weeks. Companions proposed interaction, filtering, readability, and data explanation. These suggestions prompted me to iterate the program step by step. The updated program enhanced interaction with users.
